# Research index

Research documents that FUNSTACK UI's platform and React bets are based on. Each doc ends with a
verdict: **adopt**, **adopt behind experimental flag**, or **not yet**.

| Doc | Topic | Verdict | Date |
| --- | --- | --- | --- |
| [react-async-apis.md](./react-async-apis.md) | React 19.3 async APIs: Actions, `useTransition`, `useOptimistic`, `useActionState`, `<ViewTransition>`, `<Activity>`, `use`, RSC boundaries | Adopt (ViewTransition/Activity stable; gesture transitions and `onDefaultTransitionIndicator` not yet) | 2026-10-15 |
| [popover-anchor-tooltip.md](./popover-anchor-tooltip.md) | Tooltip via Popover API (`hint`), `interestfor`, Invoker Commands, CSS Anchor Positioning, `@starting-style`; React 19.3 attribute support | Adopt Popover API + Anchor Positioning + `@starting-style`; `popover="hint"` and `interestfor` behind experimental flag (Safari lacks `hint` in 27.0; `interestfor` is Chromium-only); `::interest-button` not yet | 2026-10-15 |
| [modern-platform-survey.md](./modern-platform-survey.md) | Survey of modern HTML/CSS features for all planned primitives: `<details name>`, `::details-content`, `hidden=until-found`, `<dialog closedby>`/`requestClose()`, customizable `<select>`, Invoker Commands, `focusgroup`, `interpolate-size`, scroll-state, View Transitions, CloseWatcher, `ariaNotify()`; React 19.3 attribute/event pass-through | Adopt `<details>`/`name`/`::details-content`, `:open`, Invoker Commands, `requestClose()`, dialog toggle events, `field-sizing`, `ariaNotify()`; flag `focusgroup`, `closedby`, customizable select, `interpolate-size`, scroll-driven animations, CloseWatcher; not yet `interestfor`, `scroll-state()`, `reading-flow`, `switch`, `overlay`. Caveat: react-dom 19.3 cannot emit `hidden="until-found"` | 2026-10-15 |
| [server-function-action-props.md](./server-function-action-props.md) | Passing a Server Function directly as an action prop: react-server-dom 19.3.1 reply serialisation rule, probe of `details` shapes (`event` enumerable / non-enumerable / getter / class / Proxy), framework `temporaryReferences` survey, client-side detectability | Adopt: `details` is a plain serialisable object with `event` as a Proxy-served virtual (non-own) property; enumerable `event` only works by accident via temporary references; non-enumerable `event` logs a misleading dev warning; detection impossible | 2026-10-15 |
| [form-controls.md](./form-controls.md) | Switch, Checkbox (incl. mixed, CheckboxGroup), RadioGroup: native `<input>` vs `<button role>`, controlled native inputs under transitions (React restore vs `useOptimistic`), `preventDefault`, hydration and form reset, radio keyboard/RTL, `indeterminate`, `switch` attribute, styling hooks | Adopt native `<input type=checkbox>` / `role="switch"` / same-name radios in `<fieldset role="radiogroup">`, rendered with `checked={optimistic}`; adopt `accent-color`, `:user-invalid`, `appearance:none` styling; not yet `switch` attribute (Safari only), `appearance: base`/`::checkmark`; reject button+hidden-input | 2026-10-16 |
