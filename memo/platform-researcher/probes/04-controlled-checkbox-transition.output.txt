
== 1 native event order (no React)
preventDefault=false: click(checked=true) -> input(checked=true) -> change(checked=true) -> after-dispatch(checked=true)
preventDefault=true: click(checked=true) -> after-dispatch(checked=false)

== 2 controlled checked, state set in a transition (no optimistic)

async=true: DOM right after click=false, after tick=false, final=true
    render checked=false pending=false | onChange event.type=click target.checked=true | render checked=false pending=true | render checked=true pending=false

== 3 checked={optimistic}, async action, resolve / reject(swallowed)
